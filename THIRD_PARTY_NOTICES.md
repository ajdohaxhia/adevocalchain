# Third-party notices and dependency manifest

ademusic Vocal Rack 2.2.0 is a local native macOS arm64 build. This file records
the exact dependencies used to build and validate the shipped bundles.

There is **no** RNNoise build, neural model, downloaded impulse response, sample
library, third-party font, or recorded vocal in the distributed package. Noise
suppression is the project's own STFT reducer; reverb is fully algorithmic; the
test fixtures are generated with deterministic oscillators and RNG seeds. The
UI asks CoreText for the system "Helvetica Neue" face.

## Source / asset provenance audit

- **Plugin source**: written for this project, except the clearly marked MIT
  phase-vocoder adaptation in `Source/dsp/PitchShifter.cpp`.
- **Pitch detector**: original project implementation (decimated YIN with
  quality-dependent windows). PitchLab's detector was inspected but not used.
- **Factory presets**: generated by `Tools/generate_presets.py` from the project
  parameter schema; names and descriptions are original. No preset data was
  copied from a commercial product.
- **Test audio**: generated at runtime. The optional `--vocal` mode only reads a
  file that the user explicitly supplies locally; no vocal is shipped.
- **UI font**: system Helvetica Neue; no font file is included.
- **Images**: `docs/vocal-rack-*.png` are snapshots of this project's own editor.

## Redistribution checklist

1. The plugin binaries and source are AGPLv3 (this build).
2. Provide the complete corresponding source, including the build scripts and
   the JUCE pin, or a written offer compliant with AGPLv3.
3. Retain the MIT notice for the adapted phase vocoder.
4. Do not describe the build as notarized, Developer ID signed, or True Peak
   validated; it is ad-hoc signed, sample-peak limited, and locally built.
5. For a closed-source product, obtain a JUCE commercial licence and separate
   permission for the original source; the MIT portion remains MIT.
